"""
ИНСТРУКЦИЯ ПО ДЕПЛОЮ В YANDEX CLOUD SERVERLESS CONTAINERS

Это намного дешевле, чем VM — платишь только за время работы!
Одна презентация (2 минуты) = ~0.1 ₽ вместо 600-900 ₽ за VM в месяц.

═════════════════════════════════════════════════════════════════

ШАГИ:

1. Установи Yandex Cloud CLI (если ещё не установлен):
   
   На Mac:
   brew install yandex-cloud/yc/yc
   yc init
   (будет спрошено несколько вопросов, ответь на них)

2. Установи Docker Desktop (если ещё нет):
   https://www.docker.com/products/docker-desktop/
   
   Открой его и дождись, пока заgreen (у неё должна быть кнопка слева внизу).

3. С Мака перейди в папку проекта и запусти деплой (одна команда):
   
   cd ~/Desktop/pptx-bot
   bash deploy.sh YOUR_FOLDER_ID
   
   (замени YOUR_FOLDER_ID на свой ID, например: b1gafmjpa3r2qs61i466)

   Скрипт:
   - Соберёт Docker-образ
   - Загрузит его в реестр Yandex Cloud
   - Выведет инструкцию, что делать дальше

4. В консоли Yandex Cloud (console.yandex.cloud):
   
   → Слева найди "Serverless Containers"
   → Нажми "Создать контейнер"
   → Заполни поля:
      - Имя: pptx-bot
      - Образ: (скопируй адрес из вывода скрипта)
      - Переменные окружения (3 штуки):
        * BOT_TOKEN: (твой токен от @BotFather)
        * YC_API_KEY: (твой API-ключ)
        * YC_FOLDER_ID: (твой Folder ID)
        * WEBHOOK_HOST: оставь пусто на этом этапе!
      - Память: 512 МБ
      - Timeout: 300 секунд (5 минут)
      - Разрешить публичный доступ: ДА
   
   → Нажми "Создать"

5. После создания контейнер выдаст URL вида:
   
   https://abc123def456-abcd1234.containers.yandexcloud.net
   
   Скопируй эту часть (БЕЗ https://):
   abc123def456-abcd1234.containers.yandexcloud.net
   
   Вернись в настройки контейнера → Переменные окружения:
   → Добавь (или измени):
      WEBHOOK_HOST: abc123def456-abcd1234.containers.yandexcloud.net
   
   → Нажми "Сохранить"

6. Готово! Контейнер перезагрузится сам.
   
   Проверь: напиши боту в Telegram /start
   Если работает — всё OK! 🎉

═════════════════════════════════════════════════════════════════

СТОИМОСТЬ:

Примерный расчёт:
- 1 презентация (2 минуты) = ~0.1 ₽ (за CPU + память)
- Генерация текста (YandexGPT): ~1–2 ₽ за презентацию
- Генерация 1 картинки (YandexART): ~5–7 ₽
- Всего на 1 презентацию: ~6–10 ₽

Если создавать 10 презентаций в день: ~100 ₽/день = ~3000 ₽/месяц.
Бесплатно входит лимит: 200 млн tokens/месяц (это примерно 40,000 презентаций из 5 слайдов!)

═════════════════════════════════════════════════════════════════

ПОЛЕЗНЫЕ КОМАНДЫ:

# Посмотреть логи контейнера:
yc serverless container logs <id-контейнера> --follow

# Удалить контейнер:
yc serverless container delete <id-контейнера>

# Обновить контейнер (после изменения кода):
1. Измени код на Маке
2. bash deploy.sh YOUR_FOLDER_ID
3. В консоли обнови образ контейнера на новый
